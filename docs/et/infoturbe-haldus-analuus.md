# Dokumenteerimisplatvormi valiku analüüs RaKo õpiportfelli loomiseks

## 1. Sissejuhatus

Käesolev on osa *Infoturbe haldamise* moodulist Raplamaa Rakendusliku Kolledži (RaKo) infoturbe spetsialisti õppekavas.  
Ülesande eesmärk on luua struktureeritud õpiportfell ning teha valitud platvormi kohta analüüs.

Lisaks teadmistebaasi loomisele tuleb võrrelda erinevaid dokumenteerimisplatvorme ja põhjendada, miks just valitud lahendus on sobivaim.

## 2. Ülesande kirjeldus

Ülesanne koosneb järgmistest osadest:

- Luua õppeprotsessi dokumenteerimiseks isiklik teadmistebaas.  
- Valida selleks sobiv platvorm.  
- Võrrelda valitud lahendust vähemalt kolme alternatiiviga.  
- Analüüsida ja põhjendada valikut.

Minu lahenduseks on **GitHub** koos GitHubi repositooriumi ja Markdown dokumentidega.

## 3. Valitud lahenduse ülevaade: GitHub

GitHub on laialdaselt kasutatav platvorm tarkvaraarenduseks, dokumentatsiooniks ja versiooni­halduseks.  
Minu lahendus kasutab:

- **GitHubi repositooriumi** - Markdown-failid, pildid ja struktuur  
- **GitHub Pages** - dokumentatsiooni avaldamine veebilehena  
- **Just the Docs teemat** - külgriba ja navigeerimine  
- **Markdowni** - lihtne ja universaalne formaat  

### Peamised eelised:

- Tasuta  
- Toetab Markdowni, pilte ja faile  
- Sisaldab sisseehitatud Wiki funktsionaalsust  
- Võimaldab dokumentatsiooni ja koodi siduda  
- Lihtsasti jagatav portfelli link  
- Tugev versioonihaldus (Git)  
- Sobib kakskeelse dokumentatsiooni jaoks  
- Madal hoolduskoormus  

## 4. Võrdlus alternatiivsete platvormidega

Võrdlusesse kaasati:

- **Atlassian Confluence**  
- **Notion**  
- **MediaWiki (ise majutatud)**
